# Specification Matrix

| Name | Description |
| --- | --- |
| [DS000-vision](specsLoader.html?spec=DS000-vision.md) | States what scriptaWorlds is for, who uses it, the principles that shape every other specification, and the boundaries of the product. |
| [DS001-coding-style](specsLoader.html?spec=DS001-coding-style.md) | Defines the language, module, dependency, layout, error-handling, file-size and verification rules that every change to scriptaWorlds source, scripts and skills must follow, including the module layout of `src/`, the reader and the print renderer. |
| [DS002-model-and-agent-execution](specsLoader.html?spec=DS002-model-and-agent-execution.md) | Defines which model and agent binary scriptaWorlds uses, how one server owns the store and resumes its queue, how a turn is invoked and timed, what the prompt requires from the agent, how the result is read back and verified, and what happens on failure. |
| [DS003-main-behavior](specsLoader.html?spec=DS003-main-behavior.md) | Defines what scriptaWorlds does for readers and operators: creating a universe from a start template or from chosen ingredients, the law composed from those ingredients, the first request, the short name the agent gives the book, the durable turn queue, importing a book the team did not write here, reviewing a frozen version with the observations and the published reports it rests on, keeping a published review as it was published, collecting what the team's independent readers said about it and comparing two versions, rewriting a chapter from selected findings or a reader's remarks, exporting a printed edition, and reading the book with live progress. |
| [DS004-universe-storage](specsLoader.html?spec=DS004-universe-storage.md) | Defines the folder contract for one universe, the fields of every file the server and the agent exchange, the ingredients and the short name of a universe, the import turn and the extraction staged inside a universe, the version archive, the snapshot mechanism, the external workspace that holds the reviews and the team's reading feedback, and the older proposed-universe catalog. |
| [DS005-http-api](specsLoader.html?spec=DS005-http-api.md) | Defines the HTTP surface of the scriptaWorlds server: routes, request bodies, response shapes, error envelope and codes, the design instrument and the start templates, the import of an uploaded book, the reviews with their published files and their approvals, reader feedback, the live event stream, job lifetime, and the access boundary. |
| [DS006-reader-interface](specsLoader.html?spec=DS006-reader-interface.md) | Defines the static browser interface of scriptaWorlds: its module tree, its four-tab start screen (Custom, Import, Library and Ingredients) that composes one request, the reading flow with numbered live slices and the icon toolbar of a chapter, the nine dialogs including the ALA sessions console that shows every run of the book and the output of the selected one, the review, report and reader-feedback surfaces, the composer and offers, the reload banner, and the state it keeps in the browser. |
| [DS007-scripta-ala-skill](specsLoader.html?spec=DS007-scripta-ala-skill.md) | Defines the narrative skill that writes one episode: its mandatory working order, its narrative invariants, the plan, chapter and offer files it requires, the ingredients and the naming duty it works under, the validator it must pass, and its dependencies and boundaries. |
| [DS008-scripta-book-export-skill](specsLoader.html?spec=DS008-scripta-book-export-skill.md) | Defines the print skill: the command line of the renderer and of the verifier that accepts an edition, the edition record that binds it to the accepted version, the editorial metadata it consumes, the language and naming rules, the accepted chapter Markdown, the per-face font requirement, the produced DOCX and PDF characteristics, and its exit codes. |
| [DS009-start-template-library](specsLoader.html?spec=DS009-start-template-library.md) | Defines the library of start templates: what a template is, how the nights of the book become one, the empty template, the index and folder split, how a reader starts a universe from one, and what creationFromTemplate composes. |
| [DS010-scripta-story-design-skill](specsLoader.html?spec=DS010-scripta-story-design-skill.md) | Defines the story-design skill: the design brief it validates, the assessment-input.v2 packet and accepted-version check behind its context, its command-line contract and exit codes, the working order it prescribes before a book or an arc is drafted, and its boundary as a separate-phase skill whose proposals reach a writing turn only through an approved transfer. |
| [DS011-scripta-prose-craft-skill](specsLoader.html?spec=DS011-scripta-prose-craft-skill.md) | Defines the prose-craft skill: the prose profile it validates, its command-line contract and exit codes, the drafting and editorial-inspection questions it answers, and its boundary as a separate-phase skill that never writes a chapter. |
| [DS012-scripta-continuity-review-skill](specsLoader.html?spec=DS012-scripta-continuity-review-skill.md) | Defines the continuity-review skill: the frozen assessment packet it reads, the field-specific deterministic integrity checks and the annotation-driven semantic review it runs, the comparison ledger from which it derives CCI and CAD, the continuity-result envelope it publishes atomically, and its read-only boundary. |
| [DS013-scripta-metrics-report-skill](specsLoader.html?spec=DS013-scripta-metrics-report-skill.md) | Defines the metrics-report skill: the frozen packet, evaluation profile, annotations and corpus it reads, the vocabulary it publishes for annotated observations together with the test that keeps that vocabulary and its validators aligned, the rule registry, the twelve metrics and eight indicators it reports with their discriminated value kinds, the two aggregate policies that decide when a composite score may exist, the five views it renders from one bundle, and its advisory, no-model boundary. |
| [DS014-scripta-import-skill](specsLoader.html?spec=DS014-scripta-import-skill.md) | Defines the import skill: the host's extraction contract, the bounded import turn and its continuation pointer, segmentation of a book that arrives without boundaries, the faithfulness rules for chapter prose and for canon, threads and atlas, the language decision, the refusals, and the dependency-free validator the host runs after every turn. |
